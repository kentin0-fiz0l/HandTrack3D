# Examples

Explore example applications to learn HandTrack3D features and patterns.

## Getting Started

All examples are available in the [GitHub repository](https://github.com/yourusername/handtrack3d/tree/main/examples).

Clone and run:

```bash
git clone https://github.com/yourusername/handtrack3d
cd handtrack3d/examples/[example-name]
npm install
npm run dev
```

## Example Templates

Start with a pre-configured template:

### Vite + React Template

```bash
npm create handtrack3d@latest my-app -- --template react
```

### Vite + Three.js Template

```bash
npm create handtrack3d@latest my-app -- --template three
```

### Next.js Template

```bash
npx create-next-app my-app --example handtrack3d
```
